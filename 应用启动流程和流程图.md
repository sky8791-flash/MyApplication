# 棋类游戏应用 - 启动流程和流程图

## 📱 应用启动流程详解

### 1. 应用启动入口

```
用户点击应用图标
      ↓
Android系统启动应用
      ↓
查找AndroidManifest.xml中的LAUNCHER Activity
      ↓
启动 MenuActivity（主菜单）
```

**AndroidManifest.xml 配置：**
```xml
<activity
    android:name=".MenuActivity"
    android:exported="true"
    android:theme="@style/Theme.App">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>
```

## 🎮 游戏启动流程

### 用户选择游戏类型

```
用户点击游戏卡片（五子棋/围棋/象棋）
          ↓
MenuActivity.onClick()
          ↓
创建Intent
          ↓
intent.putExtra("GAME_TYPE", "GOMOKU/GO/XIANGQI")
          ↓
startActivity(intent)
          ↓
跳转到 GameActivity
```

## 📜 历史记录流程

```
用户在MenuActivity点击"对战历史"
          ↓
创建Intent
          ↓
startActivity(HistoryActivity)
          ↓
HistoryActivity.onCreate()
          ↓
GameHistoryManager.getRecords()
          ↓
从SharedPreferences读取JSON数据
          ↓
解析为GameRecord对象列表
          ↓
显示在RecyclerView/ListView中
          ↓
用户查看历史记录
```

   ↓

   ↓

   ↓

   ↓

   ↓
onStop()
   ↓
【MenuActivity在后台】
   ↓
用户从GameActivity返回
   ↓
onRestart()
   ↓
onStart()
   ↓
onResume()
   ↓
【重新活动状态】
```

```
startActivity()
   ↓

   ↓

   ↓

   ↓

## 📋 关键流程总结

### 1. 启动流程
```
图标点击 → MenuActivity启动 → 显示主菜单 → 等待用户选择
```

### 2. 游戏流程
```
选择游戏 → GameActivity启动 → 初始化引擎 → 选择模式 → 开始对弈
```

### 3. AI对战流程
```
选择难度 → 创建AI → 玩家落子 → AI计算 → AI落子 → 循环直到结束
```

### 4. 蓝牙对战流程
```
扫描设备 → 建立连接 → 发送邀请 → 接受对战 → 数据同步 → 对弈
```

### 5. 历史记录流程
```
点击历史 → HistoryActivity启动 → 读取数据 → 显示列表
```

## 🔧 技术要点

### Intent传递数据
```java
// MenuActivity 传递游戏类型
Intent intent = new Intent(MenuActivity.this, GameActivity.class);
intent.putExtra("GAME_TYPE", "GOMOKU");
startActivity(intent);

// GameActivity 接收游戏类型
String gameType = getIntent().getStringExtra("GAME_TYPE");
```

### 蓝牙消息协议
```json
// 对战邀请
{"type": "challenge", "from": "Player"}

// 接受对战
{"type": "accept"}

// 移动数据
{
  "type": "move",
  "r": 7,
  "c": 7,
  "color": 1,
  "gameType": "GOMOKU"
}

// 悔棋请求
{"type": "undo_request"}

// 同意悔棋
{"type": "undo_ok"}
```

### 游戏记录保存
```
GameActivity (游戏结束)
        ↓
  saveGameRecord()
        ↓
  创建 GameRecord 对象
        ↓
  GameHistoryManager.addRecord()
        ↓
  序列化为JSON
        ↓
  保存到SharedPreferences
```
